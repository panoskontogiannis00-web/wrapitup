(w)Rap it Up! — η δική σου mini εφαρμογή
==========================================

ΤΙ ΕΙΝΑΙ ΚΑΘΕ ΑΡΧΕΙΟ
  index.html     η εφαρμογή (player, "Τώρα παίζει", ιστορικό)
  manifest.json  όνομα, εικονίδιο και χρώματα όταν "εγκαθίσταται" στο κινητό
  sw.js          κρατάει την εφαρμογή στο κινητό για να ανοίγει γρήγορα
  icons/         τα εικονίδια

ΑΝΕΒΑΣΜΑ ΔΩΡΕΑΝ ΣΤΟ GITHUB PAGES
  1. github.com → Sign up (δωρεάν, χωρίς κάρτα).
  2. Πάνω δεξιά "+" → New repository
       Repository name:  wrapitup
       Public
       → Create repository
  3. Πάτα "uploading an existing file".
  4. Σύρε ΜΕΣΑ ΟΛΑ τα αρχεία ΚΑΙ τον φάκελο icons (όπως είναι, όχι το zip).
     → Commit changes
  5. Settings → Pages (αριστερά)
       Source: Deploy from a branch
       Branch: main   /(root)   → Save
  6. Περίμενε 1-2 λεπτά. Η εφαρμογή σου θα είναι στο:
       https://ΤΟ-USERNAME-ΣΟΥ.github.io/wrapitup/

ΕΓΚΑΤΑΣΤΑΣΗ ΣΤΟ ΚΙΝΗΤΟ (αυτό στέλνεις στους φίλους σου)
  iPhone:  άνοιξε το link στο Safari → Κοινοποίηση ⬆ → "Προσθήκη στην οθόνη Αφετηρίας"
  Android: άνοιξε το link στο Chrome → κουμπί "Εγκατάσταση εφαρμογής" (ή ⋮ → Εγκατάσταση)

ΑΝ ΑΛΛΑΞΕΙ Η ΔΙΕΥΘΥΝΣΗ ΤΟΥ ΣΤΑΘΜΟΥ
  Άνοιξε το index.html, βρες τη γραμμή  const SERVER = "..."
  και βάλε τη νέα διεύθυνση. Ξανανέβασέ το στο GitHub.

ΚΑΛΟ ΝΑ ΞΕΡΕΙΣ
  - Η εφαρμογή παίζει μόνο όταν η εικονική μηχανή είναι ανοιχτή (όπως και η σελίδα).
  - Στο GitHub ΔΕΝ ανεβαίνει κανένας κωδικός, κανένα τραγούδι, τίποτα από το σπίτι σου.
    Μόνο η "βιτρίνα" που δείχνει στο τούνελ.
