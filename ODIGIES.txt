(w)Rap it Up! — οδηγίες
=======================

ΤΙ ΕΙΝΑΙ ΚΑΘΕ ΑΡΧΕΙΟ
  index.html           η εφαρμογή (player, παραγγελίες, ιστορικό)
  manifest.json        όνομα, εικονίδιο και χρώματα όταν "εγκαθίσταται" στο κινητό
  sw.js                κρατάει την εφαρμογή στο κινητό για να ανοίγει γρήγορα
  icons/               τα εικονίδια
  azuracast-theme.css  το ίδιο στιλ για τη σελίδα του AzuraCast (ΔΕΝ χρειάζεται στο GitHub)
  README.md            η περιγραφή που φαίνεται στη σελίδα του repository

ΕΝΗΜΕΡΩΣΗ ΣΤΟ GITHUB
  1. github.com → repository "wrapitup" → Add file → Upload files
  2. Σύρε μέσα ΟΛΑ τα περιεχόμενα του φακέλου (και τον φάκελο icons)
  3. Commit changes
  4. Περίμενε ~10 λεπτά. Στο κινητό κλείσε και ξανάνοιξε την εφαρμογή δύο φορές.

ΣΤΙΛ ΓΙΑ ΤΗ ΣΕΛΙΔΑ ΤΟΥ AZURACAST
  Άνοιξε το azuracast-theme.css, αντέγραψε ΟΛΟ το κείμενο και επικόλλησέ το στο:
  Διαχείριση σταθμού → Δημόσιες Σελίδες → Επωνυμία → Προσαρμοσμένο CSS → Αποθήκευση
  (σβήσε πρώτα ό,τι υπάρχει εκεί)

ΑΝ ΑΛΛΑΞΕΙ Η ΔΙΕΥΘΥΝΣΗ ΤΟΥ ΣΤΑΘΜΟΥ
  Στο index.html άλλαξε τη γραμμή  const SERVER = "..."  και ξανανέβασέ το.

ΚΑΛΟ ΝΑ ΞΕΡΕΙΣ
  - Η εφαρμογή παίζει μόνο όταν η εικονική μηχανή είναι ανοιχτή.
  - Στο GitHub δεν υπάρχει κανένας κωδικός ούτε τραγούδι, μόνο η "βιτρίνα".
